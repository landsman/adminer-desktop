Database logos for the saved-connection cards, one per adminer driver id (`server` is MySQL,
`mariadb` the same driver when the server reports MariaDB). From
[simple-icons](https://simpleicons.org) 13.21.0, CC0, with the `<title>` removed and the fill set
to `currentColor` so the card tints them. `database.svg` is ours: the fallback for a driver with
no logo here (MS SQL — simple-icons dropped Microsoft's).
